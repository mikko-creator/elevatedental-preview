## Read this before sharing

Every page carries `<meta name="robots" content="noindex">`, deliberately. The treatment
prices published across this site are **representative market figures, not this practice's
own quoted fees**. `robots.txt` is inert here because crawlers read it only at an origin
root and this is a project subpath, so `noindex` is the protection that actually works.

`privacy-policy` and `terms` are **interim notices**. They state plainly that they are
interim, and they contain no invented legal text: no retention period, lawful basis, named
processor, governing jurisdiction, liability limitation or warranty. They are stand-ins to
be replaced with counsel-approved documents, not substitutes for them.
